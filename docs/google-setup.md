# Настройка Google Sheets API (10 минут)

Нужна для чтения ВСЕХ строк вкладки «Реестр» — включая скрытые фильтром.

## Шаг 1 — Google Cloud Console

1. Откройте https://console.cloud.google.com
2. Создайте новый проект: **«Bureau Dashboard»**
3. Перейдите в **API и сервисы → Библиотека**
4. Найдите **Google Sheets API** → Включить

## Шаг 2 — Сервисный аккаунт

1. Перейдите в **API и сервисы → Учётные данные**
2. Нажмите **Создать учётные данные → Сервисный аккаунт**
3. Имя: `bureau-dashboard`, нажмите **Создать и продолжить → Готово**
4. Кликните на созданный аккаунт → вкладка **Ключи**
5. **Добавить ключ → Создать новый ключ → JSON**
6. Скачается файл `bureau-dashboard-XXXX.json`

## Шаг 3 — Доступ к таблице

1. Откройте скачанный JSON, найдите поле `"client_email"` — скопируйте адрес
   (выглядит как `bureau-dashboard@....iam.gserviceaccount.com`)
2. Откройте Google Таблицу
3. Нажмите **Поделиться** → вставьте email сервисного аккаунта → **Читатель** → Отправить

## Шаг 4 — GitHub Secrets

Перейдите в репозиторий → **Settings → Secrets and variables → Actions**

Добавьте секрет **GOOGLE_CREDENTIALS**:
- Значение: всё содержимое скачанного JSON-файла (скопируйте целиком)

## Шаг 5 — Telegram (опционально)

Для получения утреннего отчёта в Telegram:

1. Напишите боту @BotFather команду `/newbot`, получите токен
2. Напишите боту @userinfobot — он покажет ваш `chat_id`
3. Добавьте в GitHub Secrets:
   - **TELEGRAM_BOT_TOKEN** = токен из BotFather
   - **TELEGRAM_CHAT_ID** = ваш chat_id (число)

## После настройки

Запустите сбор вручную:
- GitHub → Actions → «Сбор данных» → **Run workflow**

Теперь скрипт будет читать ВСЕ строки Реестра, игнорируя фильтры.
